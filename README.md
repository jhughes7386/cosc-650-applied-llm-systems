# COSC 650: Applied LLM Systems

An applied LLM systems portfolio documenting experiments, assignments, and projects developed throughout COSC 650 at Maryville University.

## Course Context

This repository contains work from COSC 650: Applied LLM Systems, an eight-week graduate course focused on building and evaluating applications using large language models. Topics include tokenization, transformer architecture, prompt engineering, function calling, retrieval-augmented generation, fine-tuning, and evaluation.

## Repository Structure

- `week-01/` through `week-08/` — Weekly assignments and notebooks
- `notes/` — Research notes and reading annotations
- `project/` — Final project code and documentation
- `CLAUDE.md` — Instructions and project context for AI coding assistants
- `README.md` — Human-facing project description
